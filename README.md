# CipherCru Payload plugins

Plugins for [Payload CMS](https://payloadcms.com) 3, built by
[CipherCru](https://ciphercru.com). Each one is its own npm package under `@ciphercru`,
versioned and released on its own.

| Plugin                                     | What it does                                                                                       | npm                                                                                                                                  |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [`analytics`](packages/analytics#readme)   | An event registry in the CMS, consent-gated delivery to GTM, GA4 and HubSpot, and a browser runtime | [![npm](https://img.shields.io/npm/v/@ciphercru/payload-analytics)](https://www.npmjs.com/package/@ciphercru/payload-analytics) |

```sh
npm install @ciphercru/payload-analytics
```

Each plugin's README covers installation, configuration and its API.
